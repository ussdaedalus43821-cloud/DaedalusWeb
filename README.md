# DaedalusTesla

**Tesla Arcade — Cybertruck Edition**: an open-world space combat sim that runs entirely in the browser, offline, from a single HTML file.

## Play

Open `index.html` — it's a "tap to play" gate that hands off to the actual game in `daedalus_tesla.html`.

- Runs fully offline (designed to run from a USB drive on a Tesla center screen)
- Gamepad and Tesla yoke support via the Gamepad API
- Fullscreen toggle available in-game

## Structure

- `index.html` — launcher / title screen
- `daedalus_tesla.html` — the game itself
